# PulseLab — Malworld 오디오 작업대

Gemini 앱 빌더가 낸 웹 오디오 편집기에 **Malworld 음향 작업에 필요한 것만** 얹은 것이다. 브라우저에서 돌고 서버로 오디오를 보내지 않는다.

```bash
npm install
npm run dev      # http://localhost:3000
```

**규격의 진실 공급원은 이 저장소가 아니라 Malworld다.** 샘플레이트·채널·피크·루프 규칙은 Malworld 저장소의 `Tools/Audio/suno-music-prompts.md`(음악)와 `Tools/Audio/veo-sfx-prompts.md`(효과음·환경음)에 있고, 이 도구는 그 규칙을 실행하는 손이다. **둘이 어긋나면 Malworld 쪽이 맞다.**

## ffmpeg을 쓰지 않는다 — 브라우저가 이미 한다

**Veo가 주는 mp4를 그대로 놓으면 오디오 트랙만 뽑힌다.** `decodeAudioData`가 컨테이너에서 오디오만 디코드하고 영상은 버리기 때문이다. 실측으로 확인했다 (2026-08-11): AAC 48 kHz 스테레오 8초 mp4가 **9 ms**만에 디코드됐다.

그래서 `ffmpeg.wasm`을 넣지 않았다. 30 MB짜리 WASM을 받아 와서 브라우저가 공짜로 하는 일을 다시 하는 셈이라 얻는 게 없다. **정말로 ffmpeg이 필요한 경우는 브라우저가 못 여는 코덱이 왔을 때 하나뿐이고**(예: mp4 안의 Opus), 그때는 그 파일 하나만 밖에서 wav로 바꿔 넣으면 된다. 임포트가 실패하면 그렇게 안내한다.

## 더한 것

**임포트에서 48 kHz로 못 박는다.** 원래는 `new AudioContext()`가 출력 장치의 레이트를 따라가서, 44.1 kHz 인터페이스를 꽂으면 **아무 경고 없이 44.1 kHz WAV가 나왔다.** 이제 `PROJECT_SAMPLE_RATE`로 고정하고, 들어온 파일이 무엇이든(mp4·mp3·wav) 그 자리에서 48 kHz PCM으로 바꿔 놓고 시작한다.

**마디 격자 (Loop Lab).** BPM·박자·다운비트를 넣으면 마디 길이가 계산되고, `N마디 선택`이 구간을 **초 소수점 넷째 자리까지 정확히** 잡는다. 마우스 드래그로는 72 BPM 32마디(106.6667초)를 못 찍는다. `마디에 맞춤`은 이미 잡은 구간의 양 끝을 가장 가까운 마디선으로 당기고, 판독줄이 **지금 선택이 몇 마디이고 격자에 맞았는지**를 계속 보여 준다.

**루프 미리듣기.** 선택 구간을 반복 재생한다. **이음매가 튀는지 들어 볼 방법이 이것뿐이라** 루프 작업에서 가장 중요한 기능이다.

**루프 제작 (꼬리 접기).** 선택을 잘라 내되 **그 뒤 `foldMs`만큼을 루프 앞머리에 등출력으로 겹쳐 섞는다.** 마디에서 그냥 자르면 마지막 화음의 잔향이 함께 잘려 루프가 도는 순간 뚝 끊기는데, 이렇게 하면 첫 표본이 정확히 `src[end]`가 되어 `src[end-1] → src[end]`로 이어진다. **길이는 정확히 유지되므로 마디 수가 흐트러지지 않는다.**

실측 (2026-08-11, 443.7 Hz 사인 · 비정수 주기 구간):

| 꼬리 접기 | 이음매 불연속 | 판정 |
| ---: | ---: | --- |
| 0 ms | 0.4310 | 딸깍 소리가 난다 |
| 5 ms | 0.0429 | 이웃 표본 최대 변화량(0.0465)보다 작다 |
| 20 ms | 0.0429 | 같음 |
| 100 ms | 0.0429 | 같음 |

**접기 길이는 이음매 값을 바꾸지 않는다** — 첫 표본은 어차피 `src[end]`라서다. 길이가 정하는 것은 얼마나 천천히 원래 앞머리로 넘어가는가이고, 그래서 **10~30 ms는 딸깍 제거, 200~500 ms는 잔향 접기**로 쓴다. 네 경우 모두 표본 수가 정확히 유지됐다.

**목표 dBFS 정규화.** 기존 `Normalize`는 피크를 0 dBFS로 올려 믹서에 남길 헤드룸을 없앤다. 저장소 규격인 **−3 dBFS**를 기본값으로 하는 버튼을 따로 뒀다.

**내보내기 이름.** `_edited` 접미사를 떼서 `music-race-v1.wav`가 그대로 나온다 — 저장소 관례가 소문자 kebab-case에 `-v1`이라 손으로 다시 고칠 일이 없다.

## 손대지 않은 것과 믿으면 안 되는 것

**`Clean Atmosphere`(스펙트럼 감산)를 쓰지 마십시오.** 이름과 달리 스펙트럼 처리가 아니다 — `audioUtils.ts`의 `analyzeNoiseProfile`이 빈을 `i % 128`로 잡는데 그건 주파수가 아니라 **샘플 인덱스**이고 FFT가 한 줄도 없다. 노이즈를 지우는 게 아니라 128표본 주기(48 kHz에서 375 Hz)의 왜곡을 넣는다. 고치지 않고 남겨 둔 것은 이 프로젝트의 자산에 쓸 일이 없어서다.

**`Gate`는 어택·릴리스가 없다.** 샘플마다 문턱 아래를 0으로 떨구므로 디지털 무음을 자르는 데는 되지만, 게이트로 쓰면 지퍼 노이즈가 생긴다.

**`vite.config.ts`가 `GEMINI_API_KEY`를 번들에 주입하는데 아무도 안 쓴다.** 앱 빌더 잔재다. 지우는 편이 낫다 — 남겨 두면 나중에 누가 키를 넣고 그게 프런트엔드 번들에 박힌다.

**`index.html`이 React·wavesurfer·tailwind를 esm.sh/CDN에서 가져온다.** `package.json`에 같은 의존성이 있는데도 importmap이 이기므로 **오프라인에서는 안 뜬다.**

## 저장소 위치

**독립 저장소다** (2026-08-11 결정). 원래 Malworld 안에 중첩돼 있었는데, 그대로 두면 `git add .`가 gitlink로 박아 내용이 따라가지 않아서 **Malworld 밖으로 옮겼다.**

그래서 Malworld 문서와는 **상대 링크로 잇지 않는다** — 두 저장소의 상대 위치가 정해져 있지 않기 때문이다. 서로를 가리킬 때는 저장소 이름과 파일 경로를 글로 적는다.
